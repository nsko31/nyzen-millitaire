NYZEN MILITAIRE — CHRONOMÈTRE PAR QUESTION

CONTENU
- index.html
- manifest.webmanifest
- sw.js

CE QUI CHANGE
- Chaque question possède son propre chronomètre (en mode Simulation).
- Le temps est personnalisable entre 5 et 600 secondes, indépendamment pour chacun des cinq tests.
- Le compte à rebours recommence pour chaque nouvelle question, pas pour la série entière.
- Lorsqu'une question comprend plusieurs écrans (mémorisation, puis réponse), le temps est partagé par ces écrans.
- Si la durée se termine : question comptée non répondue, puis nouvelle question avec son propre temps.
- Le mode Entraînement libre reste sans chrono.
- Le nombre de questions peut être choisi parmi 5, 10 ou 20.
- Les préférences et l'historique restent sauvegardés localement sur chaque appareil sous les mêmes clés que la version précédente.

MISE À JOUR SUR GITHUB PAGES
1. Dans ton dépôt GitHub NYZEN MILITAIRE, remplace le contenu du fichier index.html par celui fourni ici.
2. Remplace également sw.js (c'est nécessaire pour actualiser le cache hors connexion).
3. Tu peux garder l'ancien manifest.webmanifest, ou le remplacer avec celui du pack.
4. Après publication, recharge le site (sur iPhone, ouvre-le une fois dans Safari connecté à Internet).
5. Choisis « Simulation (chrono par question) » et entre par exemple 30 secondes pour les tests souhaités.

IMPORTANT
Les temps configurés ne sont pas présentés comme durées officielles des tests belges.
Les résultats sont locaux à chaque appareil : ils ne se synchronisent pas automatiquement entre iPhone et PC.
Le comptage du test 5 correspond à des caractères différents à la même position, sur des chaînes de longueur identique.
